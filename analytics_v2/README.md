# Historical market analytics upgrade
Use the original schema.sql and licensed historical dataset to populate a SQLite database. Source: https://www.kaggle.com/datasets/leomauro/brazilian-stock-market-data-warehouse . Data is not bundled. Install pandas, numpy and matplotlib, then run python analytics_v2/report.py path/to/warehouse.db. SQL adds close-to-close returns, intraday returns, moving averages and data validation; Python exports sector summaries and rolling 20-observation volatility. These are unadjusted price returns, not total returns; splits/dividends can distort them. No investment recommendation or backtest is claimed. Import stock_returns.csv and sector_summary.csv into Power BI for separate report pages; do not join the aggregated table to the fact table. Example DAX: Total Volume = SUM(stock_returns[volume]); Mean Daily Return = AVERAGE(stock_returns[daily_return]). Use date and sector slicers, trend lines and quality checks. A native PBIX is not included. Actual historical results require the source database.
